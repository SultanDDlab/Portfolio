# Alma project page

Place these files in your existing website:

```text
monolith-audio/
├── index.html
├── styles.css
└── projects/
    ├── alma.html
    └── project.css
```

Link the project from your homepage:

```html
<a class="project" href="projects/alma.html">
```

Before publishing, replace:

- `your@email.com`
- `Add project year`
- Instagram and SoundCloud placeholders
- Next-project title and link
- The exact music recording and performer
- The exact Creative Commons license and source URL, if applicable
